## 一、正——先立一个样本

### 第一眼层：先改哪一层

**结论表**：每行一个检查项，`检查名 · PASS/FAIL · 证据 · revision`。
用户第一眼看的不是检查脚本，是这张表——它直接回答「能不能进入小批训练设计」，放行或挡住后面所有训练动作。检查要**小而明确**：每项可独立判 PASS/FAIL 即可，不追求模板逐字节等同（官方配方明说简化训练模板的 adapter 可与完整推理模板配合，见 `decision.md` 反对侧证据）。

**一个当场能做的检验**：想到 ReJev 推进，第一个碰到的判断就是「模板/结束标记/mask/解析对齐了吗」。这张表就是这个判断的载体。

### 参照物：照着什么做

| 给什么 | 具体是哪一份 | 照它的哪一层 |
|---|---|---|
| 我自己的旧作 | `LLM01-kaizhi`（commit `cec997a`，来源表 R6） | 底座/LoRA **同题评测的记录结构**：逐题对照、比较口径分列。**不照**它的宽松字母抽取、Alpaca 模板、4-bit/A100 配置 |
| 别人的成品 | tev1 原仓（R4）＋ MiniCPM 官方模型卡/TRL 配方（R5） | tev1 照**任务语义 schema**（`state + question + options → 字母`）与推理协议参数（regex 约束、`temperature=0`、`max_tokens=8`、关 thinking）；MiniCPM 官方照 chat 模板、assistant 结束标记 `<|im_end|>`、LoRA 目标层这些**事实**。**不照抄**它的 Qwen 预渲染文本与评测目标 |
| 同一对象的上一版 | 无——`src/align/` 是本系统第一个作品单元 | — |

自己的旧作可照搬，**但先确认权利与时效**；别人的**只读借鉴**——读懂再自己写。

### 硬约束：可判定的那几条

1. 每个检查项输出固定四元组：**检查名 · PASS/FAIL · 证据（token id 与渲染原文对照） · 所钉 revision**；缺任一字段即该项不合格。
2. 对齐对象唯一：`openbmb/MiniCPM5-2B` @ 固定 commit revision；一次检查全程 revision 不变，报告里 revision 至少出现一次。
3. loss mask 断言到 ±0 token：被监督 token 恰为答案 span，报告须贴出 mask 首尾 token 的原文对照。
4. 结束标记三处分别核对才算数：训练模板 assistant 结束（`<|im_end|>`）、推理停止配置、约束解码允许字母集；不得用 `tokenizer.eos_token` 机械拼接替代（它与 `<|im_end|>` 不同）。
5. 答案解析只认完整单字母：字母集显式写在配置里（数据规格锁定前不得硬编码假设范围）；多字母/非字母/空输出一律记 invalid、计入无效率，不许抽取后计入正确。
6. 模块零 GPU、离线可跑：不依赖 Modal；训练数据不进模块——用自造的代表性合成样例做检查。

**能数的才能查。** 上面六条每条都能数；「对齐质量高一点」查不了。

### 要几版，各是什么角度

| 版本号 | 角度 | 一句话说明 |
|---|---|---|
| v1.a | 最小黑盒 | 只用 tokenizer/config 级做模板渲染＋mask 断言，不碰权重，最便宜 |
| v1.b | 迁移对照 | tev1 原始渲染 vs MiniCPM 重渲染的逐 token diff，给出「为什么必须重渲染」的证据 |
| v1.c | 红军版 | 从「答案解析能被怎样骗」出发写对抗样例（多字母/小写/空输出/thinking 残留），验证 invalid 判定 |

**变体一律带编号。** 一句「这个更好」，三天后没人知道指的是哪一个。

**把样本做便宜，再做好：** v1.a 就是「线框图」——不加载权重就能出结论；三个角度互问「你那版查到了什么我查不到的」，再合成一套。

## 三、合——被攻击之后，还剩什么

> 本轮「攻击」来自研究阶段的来源核查（取舍卡两侧最强证据互攻），还不是对第一版的攻击。
> 对作品本体的正反合，要等 v1 ＋ 亲改之后再走一遍。

### 被攻击后仍然成立的

1. 「从任务数据重渲染，而不是仅替换模型名」——tev1 数据规范（Qwen 预渲染）与 MiniCPM 官方配方互攻后仍站得住。
2. 对齐检查**小而明确**：官方配方允许简化训练模板与完整推理模板配合，所以逐字节等同不是门槛，输出无误才是。
3. 三条不可妥协约束（数据口径 / 模板可证实 / Modal 可计费可停止）作为外部边界保留；本模块只负责第 2 条的实证。

### 被攻击掉的（记下来，免得下次又捡回去）

1. 「约 $17 / 25 分钟可作预算参考」——平台、底座、口径全不同，且无历史账单佐证。
2. 「tev1 `instruction` 数据可直接喂 MiniCPM」——绑定 Qwen tokenizer 预渲染，必须重渲染。
3. 「必须逐字节复刻官方完整模板」——官方自己的配方否定了这个必要性。

新开一个空会话，只喂三样：**标准原件**（第二节写下的那份文件）、本文件、`negatives.md`，
让它出一版，然后看两件事：

- [ ] `check.sh` 跑得过吗

想改——把这次改动补回第二节，再跑一遍。
**跑不过、或者还想大改，说明标准还没定完。**

放行之后，规矩就变了：**标准从此先于产出**——第二版起，生成前先读本文件，
生成后跑 `check.sh`，把判好坏降级成判对错；发现标准本身错了，就改标准，
**标准随产出一起演化**。
