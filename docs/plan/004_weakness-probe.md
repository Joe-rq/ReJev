# 004 弱项探针：容量 vs 训练充分度（待执行）

日期：2026-09-25。前序：exp003（Issue #1）。项目所有者已批：**先跑 B. 容量探针**。

## 问题

exp003 的**细粒度诊断**（零成本，本地逐题结果）确认：ReJev-2B 与 Tev1-4B 的差距**不是**形式属性造成的——

| 假设 | 证据 | 判定 |
|---|---|---|
| 长上下文 | prompt 1,000–1,500 token 段 ReJev **100%** | ❌ |
| 多选项 | `research_taxonomy_v21`（24 选项）ReJev **100%** | ❌ |
| 训练数据量 | 同 source 内部各变体**训练量完全相同**（policy_v2 各 1,900；routing_v2 各 950），表现却差 **26–33pp** | ❌ |
| 模式坍塌 | 预测字母分布 ≈ gold 分布 | ❌ |
| **任务语义难度** | 弱项集中在特定变体：`decisive_missing` 67%、`complete_positive` 67%、routing `complete_*` 60.5–66.7%、`sst5` 各情感类 41–73% | ✅ |

**本轮要回答**：这些弱项是**训练不充分**（可继续投入）还是 **2B 容量上限**（应转更大底座/第二阶段）？

关键旁证：`decisive_missing` 上 base 仅 **6.0%**（远低于随机 1/3），说明 base 存在强答案偏置、该任务需要真正学会一条判断规则；Tev1-4B 达 **100%**，证明任务可解。

## 设计

**单一变量**：LoRA rank `r=16 → r=64`（`alpha` 同步 `32 → 128`），其余配方与 exp002 **逐字相同**
（lr 2e-4、1 epoch、seq 2048、all-linear、seed 42、L4、MiniCPM5-2B @ `12a3808`）。

**判读规则（预注册，训前锁定）**：

| 结果 | 结论 | 下一步方向 |
|---|---|---|
| 新封存集总体 **≥ +3pp** 且弱项变体同步提升，强项不退化 | **容量受限** | 值得继续加容量 / 考虑更大底座 |
| 变化 **< +1pp**（在噪声内） | **非容量问题** → 指向训练充分度 | 再跑 A. 2 epoch 探针 |
| 强项退化 >2pp | 容量换能力失败 | 回退，重新设计 |

**同时记录** train_loss 作旁证：若 loss 明显更低而准确率不动 ⇒ 模型是在拟合噪声而非学习规则。
