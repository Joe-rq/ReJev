# exp006 · 干净权重轮：剔除受限语料后重训（Issue #8）

日期：2026-09-25 方案 / 09-26 训练 / 09-27 评测。方案：[docs/plan/006_clean-weights.md](../../plan/006_clean-weights.md)。
**结论一句话**：剔掉 `ag_news`＋`sst5`（3,159 条）后按同配方重训，**保留源子集仅 −1.31pp（CI 贴 0）**，总体 −2.33pp 落预注册灰带；受限源 −12.32pp 是「没学过」的直接体现。许可链干净的 adapter 已产出。

## 问题与判据（预注册；含一次训前修订）

**问**：剔除许可受限语料（AG News 明示 non-commercial、SST-5 全链零授权，依据 [NOTICE](../../../NOTICE) 的数据许可节）后重训，能力掉多少？

**切分（存量口径，更正过 issue 原文）**：训练 = `rejev2-train` 剔源 = **30,987**（issue 字面的 32,623 会与 holdout2 泄漏 1,497 条）；评测 = holdout1(1,892，已降级开发集) ＋ holdout2(1,802) = **3,694**，双口径零泄漏实测 0/0。

**配方修订（训前，依据 004 判读的预注册例外）**：原拟与 004 同配置 r64——004 判定 r64 全面崩坏（−23.31pp，[exp004](../exp004-capacity-probe/README.md)）→ 例外触发，**退回 r16/α32**（与 exp002 逐字相同，仅训练集变）。代价：主对照变为 `clean-r16` vs `exp002-r16`，**「剔源」与「切分」两项共变，差值不作归因**——本轮只能回答「换掉这批语料后总体差多少」，不能回答「剔源本身值多少 pp」。

**判读档位（训前锁定）**：|Δ|<1pp 未检出；1–3pp 「可察觉未达实质门槛」（报点估计＋组聚类 bootstrap CI，不作归因）；≥3pp 实质差异。受限源（341）与保留源（3,353）子集单列。

## 判读

1. **干净版权重成立**：保留源 −1.31pp（CI 贴 0）说明剔掉 9.2% 受限语料对干净源的能力没有实质损害；总体 −2.33pp 主要由受限源大跌稀释贡献。
2. **boolq 的 −7.9pp 是保留源里唯一显眼异常**（86.0%→78.1%）。boolq 在 clean 训练集里，本不该「没学过」。候选解释：切分差异（holdout2 抽走 142 条 boolq 训练题，占其保留训练量的 5%）或剔源的间接效应——**共变之下无法归因，登记不裁断**。发布报告若引 boolq 数字，须带此注。
3. **受限源 −12.32pp 是换语料的直接读数**：ag_news 从 89% 掉到 79.5%（仍高于 base 76.7%，模型有部分泛化），sst5 从 57.4% 掉到 43.1%（高于 base 37.9%）。「没学过但没归零」——底座先验＋任务相似性仍在。
4. **policy 98%→100% 是唯一提升**，幅度小（n=147），不解读。

## 诚实记录（三条，不粉饰）

1. **本轮不存在「未参与调参的最终评测集」**：配方（r16）依据 004 在 holdout2 上的失败结果调整过；评测集本身含 holdout1（已被 exp002/003/005 消费的开发集）。按 plan 003 封存纪律，**这两个集都已失去「处女评测」资格**。将来若需无污染终评，须另建新集。
2. **消融弱化**：主对照两项共变（剔源＋切分），−2.33pp **不能**写成「剔源的代价」。恢复纯消融需补 `probe-r16`（34,146 含源/切分 B，≈$3.9）——本轮 credit 不够未做，留作可选项。
3. **004 训练集身份不可代码自证**（其脚本只断行数不校内容）：已下载 Volume 副本与本地逐位一致，证明「核对时一致」，不能排除「训练后被替换」。属 004 的凭据问题，不影响本轮结论（本轮对照臂是 exp002-r16，其数据身份 exp002 已封存）。
