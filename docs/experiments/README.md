# experiments — 有界小实验

> 让方案由数据定，不拍脑门。**一个实验一个目录**：`exp001-<slug>/`，编号连续，绝不与主目录混住。
> 什么时候用：**方向没定，且这道难题多年没解决**——那就不可能今天拍脑袋解决，不然早解决了。
> 输入不清楚（输出清楚、不知道拿什么喂）时同样适用。一组十个跑完，通常就明白了。
> 每个实验目录内放：`readme.md`（假设 / 做法 / 结论 / **结论的时间边界与规模边界**）+ 过程材料。
